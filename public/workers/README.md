# public/workers — controlled runtime assets

This directory is **not** a Turbopack/Next media-copy dump.

## `eDefterAnalyze.worker.js`

- **What:** Classic IIFE Web Worker for `E_DEFTER_CONTROL` / `GENERAL_LEDGER_CONTROL`.
- **How:** Generated by `node ./scripts/bundle-edefter-analyze-worker.mjs` (esbuild).
- **When:** Also run automatically before `next build` via `scripts/run-production-build.mjs`.
- **Why:** Turbopack copies `src/workers/eDefterAnalyze.worker.js` into `.next/static/media/` without resolving `@/` imports, which causes `WORKER_ONERROR` and a permanent main-thread fallback.
- **Load URL:** same-origin `/workers/eDefterAnalyze.worker.js` (Next static `public/`, JS Content-Type).
- **Bridge:** `runEDefterAnalyzeWorker` uses `classicWorker: true` (no `type: "module"`).

Do not hand-edit the generated file. Change `src/workers/eDefterAnalyze.worker.js` (and engine deps), then re-run the bundle script. CI/tests fail if the committed bundle is stale relative to a fresh rebuild.
